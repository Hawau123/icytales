# 🍦 IcyTales – Ice Cream E-Commerce Website

A modern and responsive ice cream e-commerce website built using **React**, **Vite**, and **Tailwind CSS**.

The project provides an engaging online shopping experience where users can browse ice cream products, search and filter items, view detailed product information, add products to a shopping cart, and proceed to checkout through a clean and user-friendly interface.

---

## ✨ Features

- Responsive navigation bar
- Hero section
- Product showcase
- Shop page
- Product search
- Category filtering
- Product sorting
- Product pagination
- Dynamic product details page
- Product image gallery
- Shopping cart
- Quantity management
- Checkout page
- Contact page
- About page
- Team page
- Responsive design
- Clean and modern user interface

## ⚙️ Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate into the project folder:

```bash
cd icytales
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```
