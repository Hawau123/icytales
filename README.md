# 🍦 IcyTales — E-commerce Website

IcyTales is a React-based e-commerce project designed to provide an engaging online shopping experience. It uses Redux Toolkit for state management and the DummyJSON API to retrieve product data.

## ✨ Features

- 🛍️ E-commerce interface for browsing products
- 🔄 Product data fetched from the DummyJSON API
- ⚛️ Reusable UI components built with React
- 🧠 Centralized state management with Redux Toolkit
- 📱 Responsive layout (where implemented)
- 🎨 Product-focused interface and styling

## 🛠️ Tech Stack

- React
- JavaScript (ES6+)
- Redux Toolkit
- DummyJSON API
- HTML5 and CSS3
- Vite (if used in this project)

## 🚀 Getting Started

### Prerequisites

- Node.js and npm installed
- Git installed

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Hawau123/icytales.git
   ```
2. Open the project folder:
   ```bash
   cd icytales
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open the local URL shown in your terminal.

> If your repository uses a different folder name or start command, adjust these instructions to match your project.

## 🌐 API

IcyTales uses the DummyJSON API to retrieve product data. API documentation: https://dummyjson.com/docs/products
